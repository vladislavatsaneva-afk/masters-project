# Audio Signal Management System

## Overview
A software system developed as part of my Master's degree in Computer Systems and Technologies at the University of Ruse "Angel Kanchev".

The system is designed to receive and process audio signals, transcribe their content, store information in a database and visualize signal locations on a city map.

## Main Features
- Submission and management of audio signals
- Audio transcription
- Database storage
- Map-based visualization of signal locations
- Operations and management of submitted signals

## Main technology
- Python

## Project Structure
- backend folder – server-side components
- frontend folder – user interface
